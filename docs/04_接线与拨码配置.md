# CW210 接线与拨码配置

> 适用于板卡：达内 CW210 / ME210-BOX 底板（S5PV210），原理图图纸 `ME210-BOX-20120621.DDB`
> 目的：记录**实测可用**的接线与拨码组合，便于后续重新搭环境时一次接对

---

## 一、调试串口（COM1）—— 最重要

### 1.1 原理图依据

`CW210-Peripherial.pdf` 第 4 页「串口电路」+「串口@USB电路」：

```
COM1  BOXCONN_DB9   ──►  U40  SP3232EEN  ──►  RSTXD0 / RSRXD0 / RSRTS0 / RSCTS0
COM2  BOXCONN_DB9   ──►  U41  SP3232EEN  ──►  RSTXD1 / RSTXD1 / RSRTS1 / RSCTS1
UART1 CON4 （4 脚 TTL 排针）
UART2 CON4 （4 脚 TTL 排针）
MAX3485 (U42) ── TXD2_485 / RXD2_485 ── RS485（走 UART2）
```

要点：

- **COM1 是 UART0，即内核里的 `ttySAC0`**，也是 u-boot 的调试口
- COM1 是 **RS232 电平**（经 SP3232EEN 转换），**不能直接用 USB-TTL 模块接**，必须用 USB 转 DB9（RS232）线
- UART1 / UART2 另有 CON4 TTL 排针，若需要可直接用 USB-TTL 接（需接 GND）

### 1.2 实测接线方式 ✅

| 板端（COM1，DB9 公/母头） | | PC 端（USB 转 DB9） |
|---|---|---|
| 2 脚 | ─── | 2 脚 |
| 3 脚 | ─── | 3 脚 |
| 5 脚 | ─── | 5 脚 |

即 **2—2、3—3、5—5 直连**（不交叉、不用零调制解调器）。

> 这三根线是 RX / TX / GND。原理图上 COM1 为 DCE 接法，直连即可与 PC 的 DTE 侧正常通信；本项目全部串口操作均在此接线下完成。

### 1.3 串口参数

| 参数 | 值 |
|---|---|
| 波特率 | **115200** |
| 数据位 | 8 |
| 校验 | 无（None） |
| 停止位 | 1 |
| 流控 | **无（None）** |

PC 侧串口名：本项目使用 `COM3`（以实际枚举为准）。

### 1.4 常见故障

| 现象 | 原因 / 处理 |
|---|---|
| 完全无输出 | 确认接的是 **COM1**（UART0），不是 COM2（UART1） |
| 只有乱码 | 波特率不是 115200；或 GND 未接 |
| 上电瞬间有几个乱码字符后静默 | TXD 悬空噪声，非启动日志。见下文「启动失败的判读」 |
| `PermissionError(13)` 打不开 COM3 | SecureCRT 等终端占用了串口（即使显示"未连接"也会锁端口），先关闭 |
| 用 USB-TTL 接 COM1 收不到数据 | COM1 是 RS232 电平（±5~12V），USB-TTL 是 TTL 电平，**不能直连**，必须用 USB 转 DB9 |

## 二、拨码开关 SW3 / SW4

### 2.1 原理图信息

- `SW3`、`SW4` 型号均为 **`NHDS_4`（4 位拨码开关）**
- 在 `CW210-Peripherial.pdf` 中两者位于第 4 页 **RS485 / UART2 电路区域**（MAX3485 U42 附近）

> ⚠️ 说明：原理图的文本层无法直接给出每个拨码位的功能定义（需看图纸连线）。下列配置为**实测可正常启动并通信**的组合，直接照抄即可。

### 2.2 实测可用配置 ✅

| 开关 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **SW3** | **ON** | **ON** | OFF | OFF |
| **SW4** | OFF | OFF | OFF | OFF |

即 **SW3 = ON ON OFF OFF，SW4 = 全部 OFF**。

### 2.3 启动方式拨码

本板正常从 **NAND 启动**，实测可用组合：

| 用途 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| **NAND 启动**（正常使用） | **ON** | OFF | OFF | OFF |
| **USB 下载**（刷机 / 救砖） | ON | OFF | OFF | **ON** |

> NAND 启动下 u-boot 会打印 `##### JFJKJ BIOS for JFJ210 #####`，随后 `Hit any key to stop autoboot`。
> 上电后 **10 秒内不要按任何键**，否则会打断自动启动倒计时，停在 `tarena #` 命令行。

## 三、USB 与网口

### 3.1 USB OTG（刷机用）

- 接口：`USBOTG`（USB_MINI），对应原理图「USB下载电路」
- 用途：进入 **USB 下载档**（拨码 1=ON、4=ON）后，由 PC 通过 DNW 载入 BL1 / BL2
- **Windows 侧必须先装对驱动**，否则 `dnw` 无法打开设备 —— 用 `tools/windows/zadig-2.9.exe` 替换为 **WinUSB**，详见 [../tools/windows/README.md](../tools/windows/README.md)

### 3.2 以太网

- 芯片：**DM9000**（16 位模式），u-boot 阶段与内核共用
- 板端 MAC（默认假 MAC）：`10:23:45:67:89:ab`
- PC 侧 IP：`192.168.1.13`
- 板子 IP：
  - u-boot 阶段：`192.168.1.100`（由 `setenv ipaddr` 设定）
  - Linux 运行时：`192.168.1.6`（需手动 `ifconfig eth0 192.168.1.6 netmask 255.255.255.0 up`）
- 网线直连 PC 即可，无需交换机

## 四、完整接线速查表

| 项目 | 连接方式 | 备注 |
|---|---|---|
| 调试串口 | 板 **COM1** DB9 的 **2 / 3 / 5** ↔ PC **USB 转 DB9** 的 **2 / 3 / 5** | RS232 电平，115200-8-N-1，无流控 |
| 以太网 | 板网口 ↔ PC 网口（直连） | DM9000，板子 `192.168.1.6` / `192.168.1.100` |
| USB 下载（仅刷机） | 板 `USBOTG`（USB_MINI） ↔ PC USB | 需 WinUSB 驱动（Zadig） |
| 供电 | DC 电源适配器 | **大文件传输时必须用适配器供电**，仅靠 USB 会因供电不足中途重启 |
| 启动拨码 | **SW3 = ON ON OFF OFF**，**SW4 = OFF OFF OFF OFF** | 实测可用 |
| 启动方式 | NAND 启动档 **1=ON、2/3/4=OFF** | 上电后 10 秒内不要按键 |

## 五、制作调试线的注意事项

1. **用手上的材料即可**：杜邦线 / 鳄鱼夹 + USB 转 DB9，接 2、3、5 三根线就能通，不需要买专用线
2. **务必接 GND（5 脚）**：只接 TX/RX 不接 GND 会出现时好时坏、乱码、丢字
3. **不要给 COM1 供 3.3V/5V**：DB9 上只接 2、3、5 三个脚，其余保持悬空，避免倒灌
4. USB 转 DB9 线要选 **RS232 电平**的（内部有 MAX3232/SP3232 之类芯片），不要误用「USB 转 TTL」的杜邦线直接怼到 COM1
5. 若串口能收到 `Uncompressing Linux... done, booting the kernel.` 之后就没输出，**先检查 `machid`**：
   - u-boot 里执行 `bdinfo`，`arch_number` 应为 **`0x00000998`**
   - 若 `machid` 被设成了 `0x3F80`，内核会在机器 ID 校验处静默死循环，表现为彻底无声
   - 修复：`setenv machid 0x998; saveenv; reset`

## 六、串口日志「正常 / 异常」判读

**正常启动（Linux）**

```
##### JFJKJ BIOS for JFJ210 #####
This Board: SDRAM is 1024MB; LCD display size is: 800X480
Hit any key to stop autoboot:  0
NAND read: device 0 offset 0x200000, size 0x500000
 5242880 bytes read: OK
Boot with zImage
Using machid 0x998 from environment

Starting kernel ...

Uncompressing Linux... done, booting the kernel.
Linux version 2.6.35.7-Concenwit (linux@linux) ... for CW210 Concenwit Tech
Machine: SMDKV210
Memory: 512MB 320MB = 832MB total
...
VFS: Mounted root (cramfs filesystem) readonly on device 31:2.
Freeing init memory: 188K
~ #
```

**异常：看到 `done, booting the kernel.` 之后就没有任何输出**

最可能的原因是 **`machid` 不对**（见 5.5）。排查顺序：

1. `bdinfo` 看 `arch_number` 是否为 `0x998`
2. 不是就 `setenv machid 0x998; saveenv; reset`
3. 仍无输出则检查 rootfs 是否为「含 OOB 的 dump」被误用 `nand write` 写入（见 [../bin/README.md](../bin/README.md)）

**异常：`cramfs: bad compressed blocksize` + `Kernel panic - not syncing: No init found`**

rootfs 数据错位。最常见原因：把 **2112 字节/页**（含 OOB）的 dump 当成 cramfs 用 `nand write` 写入。改用干净的 `rootfs.cramfs`（2048 字节/页）。
